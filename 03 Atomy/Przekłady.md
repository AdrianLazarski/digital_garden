Uproszczona wersja języka CLS:
	Słownik: p1, p2, p3, ˄, ˅, ~

Uproszczona teoria zbiorów
Słownik: x, =, ∈, X1, X2, X3, (), ˄, ˅, ~

Zbiór wyrażeń sensownych: wyrażenia atomowe x∈Xi, a→b itd.

FOR - formuły

Przekład

"* : "FORcls→FORtz "* :"
	1. (a)* =: x∈Xi, gdzie a=pi
	2. (~a)* =: ~(a)*
	3. (a˄b)* = :(a)* ˄ (b)*
	4. (a˅b)* = :(a)* ˅ (b)*

Termy algebry zbiorów
Słownik: Z1,Z2, Z3, -, =, 1, ∩, ∪

Wyrażenia sensowne: Z1, Z1∩Z2, Z1∪Z2, Z1-Z2, Z1=Z2

°:FORcls→termy AZ
	1. (pi)°=:Xi
	2. (~pi)°=: -(Xi)
	3. (pi˄pj)°=:(Xi)∩(Xj)
	4. (pi˅pj)°=:(Xi)∪(Xj)
